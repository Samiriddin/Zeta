# 📱 Zeta PWA — Демо-версия

Мобильное приложение Zeta в виде PWA (Progressive Web App).

## 🎯 Что это

**Демо-макет** мобильной версии Zeta. Работает **офлайн**, можно **установить на телефон**.

⚠️ **Это демо** — ответы заранее заготовлены.
Полная версия работает на ПК с настоящим ИИ.

## 📁 Файлы

| Файл | Что |
|------|-----|
| `index.html` | Главная страница |
| `style.css` | Стили (тёмная/светлая тема) |
| `app.js` | Логика чата, настройки |
| `manifest.json` | Описание PWA |
| `service-worker.js` | Офлайн-кеш |
| `icon-192.png` | Иконка 192×192 |
| `icon-512.png` | Иконка 512×512 |

## 🚀 Как запустить

### Локально

1. Открой `index.html` в браузере
2. Всё работает (кроме установки — нужен HTTPS)

### На GitHub Pages

1. Залей файлы в репозиторий
2. Settings → Pages → Source: `main`
3. Папка: `/pwa`
4. Через 2 минуты ссылка: `https://samriddin.github.io/Zeta/pwa/`

### Установка на телефон

1. Открой ссылку на телефоне (Chrome/Edge)
2. Меню (⋮) → **«Установить приложение»**
3. Иконка **Zeta** появится на главном экране
