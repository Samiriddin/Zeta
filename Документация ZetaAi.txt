## 🚀 О ПРОЕКТЕ

### Что такое Zeta?

**Zeta (Зета)** — это умная и саркастичная ИИ-помощница для Windows в виде виджета. Она работает полностью локально, бесплатно и имеет доступ к интернету для поиска информации.

**Программная Zeta — это прототип.** Следующий этап — физический робот Z (вдохновлён V из Murder Drones), где Zeta станет мозгом реального тела. Виджет на ПК и робот Z — одна личность, два тела.

### Ключевые особенности

| # | Особенность | Описание |
|---|-------------|----------|
| 1 | 🔒 **Полностью локально** | Все данные хранятся на вашем ПК. Никаких облачных серверов. |
| 2 | 💰 **Бесплатно** | Никаких подписок, платежей или платных API. Всё открытое ПО. |
| 3 | 🎭 **Имеет характер** | Вдохновлена V из Murder Drones — холодная, саркастичная, но заботливая. |
| 4 | 🧠 **Умная** | Чат, зрение, код, файлы, Git, RAG, перевод, поиск. |
| 5 | 📱 **Доступна везде** | ПК-виджет, Telegram (2 бота), веб-интерфейс. |
| 6 | 🎤 **Говорит** | 6 нейронных голосов (edge-tts). |
| 7 | 👁️ **Видит** | Анализ экрана через LLaVA. |
| 8 | 📄 **Читает документы** | PDF, Word, Excel, TXT через RAG. |

## 📥 УСТАНОВКА И НАСТРОЙКА

### Шаг 1: Клонирование проекта

```bash
mkdir D:\Zeta
cd D:\Zeta
```

### Шаг 2: Установка Python

Скачайте и установите Python 3.12+ с [официального сайта](https://python.org)

```bash
python --version  # Должно быть 3.12+
```

### Шаг 3: Установка зависимостей

```bash
# Основные
pip install PyQt6 requests pillow mss edge-tts playsound

# Telegram
pip install python-telegram-bot

# Система и мониторинг
pip install psutil wmi

# Веб-интерфейс
pip install Flask flask-cors

# RAG (документы)
pip install PyPDF2 python-docx openpyxl chardet

# Опционально
pip install pygetwindow  # Для определения активного окна
```

### Шаг 4: Установка Ollama

Скачайте и установите [Ollama](https://ollama.ai/)

```bash
# Установите переменную окружения
$env:OLLAMA_MODELS = "D:\ollama_models"

# Или навсегда (PowerShell от администратора)
[Environment]::SetEnvironmentVariable("OLLAMA_MODELS", "D:\ollama_models", "User")

# Загрузите модели
ollama pull qwen2.5:7b
ollama pull llava:latest
ollama pull mistral:latest        # опционально
ollama pull llama3.2:3b          # опционально
ollama pull phi3:mini            # опционально
ollama pull gemma:2b             # опционально
```

### Шаг 5: Настройка Telegram-ботов

1. Найдите в Telegram **@BotFather**
2. Создайте **личного** бота:
   - `/newbot` → `Zeta AI Assistant` → `@ZetaAI_Bot`
   - Скопируйте токен
3. Создайте **публичного** бота:
   - `/newbot` → `Zeta Public AI` → `@ZetaPublicBot`
   - Скопируйте токен
4. Вставьте токены в `zeta_bot.py` и `zeta_public_bot.py`

### Шаг 6: Настройка переменных окружения

Создайте файл `.env` в корне проекта:

```env
OLLAMA_MODELS=D:\ollama_models
ZETA_TOKEN=ваш_токен_личного_бота
PUBLIC_TOKEN=ваш_токен_публичного_бота
```

## 📄 RAG (ДОКУМЕНТЫ)

### Что такое RAG?

**RAG (Retrieval-Augmented Generation)** — технология, которая позволяет Zeta читать ваши документы и отвечать на вопросы по ним.

### Поддерживаемые форматы

| Формат | Расширение | Библиотека |
|--------|------------|------------|
| Текст | `.txt` | Встроенная |
| PDF | `.pdf` | PyPDF2 |
| Word | `.docx` | python-docx |

## 🤖 ФИЗИЧЕСКИЙ РОБОТ Z

### Концепция

**Z — физическая версия Zeta.** Робот вдохновлён V из мультфильма Murder Drones (без оружия, кислоты, крыльев и хвоста).

- Рост: ~155 см
- Скелет: алюминиевые трубки
- Корпус: 3D-печать (PETG)
- Мозг: Raspberry Pi 5 (торс)
- Глаза: OLED-экраны 1.5"
- Зрение: камера-модуль
- Слух: USB-микрофон
- Голос: динамик 5W
- Связь: WiFi с ПК (где живёт Zeta)

### Общая схема тела

```
        ГОЛОВА (~25 см)
    ┌───────────────┐
    │ [Экран][Экран]│  ← глаза (OLED)
    │     (рот)     │  ← динамик
    └───────┬───────┘
            │ шея (шарнир)
    ┌───────┴───────┐
    │   ГРУДЬ/ТОРС  │  ← Raspberry Pi + аккумулятор
    │    (~50 см)   │
    ├───┬───────┬───┤
   РУКА │       │  РУКА
 (~40см)│       │(~40см)
    │   ├───────┤   │
    │   │  ТАЗ  │   │
    │   │(~20см)│   │
    │   └───┬───┘   │
    │       │       │
    └── НОГИ (~40 см)┘

Итого высота: ~155 см
```

### Роль мини-сервера (Raspberry Pi 5)

- Полноценный "мозг" робота внутри корпуса (в груди/торсе)
- Управляет моторами, камерой, микрофоном, динамиком
- Работает автономно от аккумулятора — не нужен подключённый ПК
- Связь с домашним ПК по WiFi для доступа к более мощной модели (Mistral) при сложных задачах
- Обрабатывает видео/звук локально — быстрая реакция, экономия трафика
- Управляет энергопотреблением и зарядкой от солнечных панелей

### Способы движения

**Ноги (этап B, сложно):**
- Шагающие, дигитигрудные (как у V) — реалистично, но требует точного баланса
- На ногу: 5-6 сервоприводов (бедро×2, колено×1, лодыжка×2-3) → 10-12 на обе ноги
- Главная сложность — баланс: нужен IMU + датчики давления + ПИД-алгоритм 100+ коррекций/сек

**Колёса (этап A, временно):**
- Скрыты под нижней частью корпуса, визуально похоже на "ноги"
- Дешевле и быстрее в реализации (~$70-90)
- Не может подниматься по лестнице
